### 🚀 Featured projects

#### 🍽️ BhojanQR — QR-based restaurant ordering SaaS
[Live](https://bhojanqr.com) · [Android app repo](https://github.com/bishwa-bandhu-parmar-06/BhojanQRMobile)

My own product. Diners scan a table QR code, browse the menu, and place orders that go straight to the restaurant's dashboard.
- Web app plus an Android app (React Native, currently in Play Store testing)
- Online payments with **Razorpay**
- Containerized with **Docker** and shipped through a **CI/CD** pipeline

#### 🏥 AATURA — Doctor & hospital appointment booking
[Repo](https://github.com/bishwa-bandhu-parmar-06/Hospital-Management)

Appointment platform connecting patients, doctors, and hospitals.
- **4 roles** (patient, doctor, hospital, admin) with role-specific JWT auth
- Appointment lifecycle: booking → pending → confirmed / cancelled, with notifications
- **Load-tested with k6** to check how the API holds up under concurrent traffic
- React (Vite) · Node.js · Express

#### 🏡 GayaRent — Rental listings for Gaya
[Live](https://gaya-rent.onrender.com/) · [Repo](https://github.com/bishwa-bandhu-parmar-06/Gaya_Rent)

Owners list properties; tenants find them and contact owners directly by call or WhatsApp, with no broker in between.
- **PostgreSQL with hand-written SQL** (raw `pg` driver, no ORM), chosen to learn relational schema design properly
- Tenant / Owner / Admin dashboards, admin approval for new owners, CSV bulk upload, location-based search
- Next.js 14 (App Router) · Express · Supabase Postgres · Tailwind + shadcn/ui

#### 🛒 MartXpress — Multi-vendor e-commerce
[Live](https://martxpress.onrender.com/) · [Repo](https://github.com/bishwa-bandhu-parmar-06/martXpress)

Multi-vendor storefront with product search, cart, and JWT authentication.
- React · Node.js · Express · MongoDB
